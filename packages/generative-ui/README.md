# @vibespace/generative-ui

ReScript package for renderer-neutral generative UI contracts.

Current responsibilities:

- XML prompt construction for raw HTML/CSS document edits.
- typed wrappers for profile/source strings and failed patches.
- Codex edit request wire conversion.
- sanitized web context records.
- trusted frame/image URL policy.
- genType TypeScript output for consumers outside ReScript.

Non-goals:

- no iframe rendering.
- no DOM selection or screenshots.
- no prompt bubble UI.
- no Vite-only resolver implementation.
- no Send Stores React Native rendering layer yet.
